# My Daily Growth — دليل التشغيل بالعربية

تطبيق سطح مكتب لتنظيم العادات والصلاة والقراية والمزاج والحاجات الجديدة اللي تعلمتيها. معمول بـ Java Swing وSQLite وبألوان وردي فاتح وDusty Rose وبيج وMauve.

## كيفاش تفتحي المشروع؟

### في IntelliJ IDEA
1. فكّي ضغط ملف ZIP.
2. افتحي IntelliJ IDEA واختاري **Open**.
3. اختاري المجلد `MyDailyGrowth` كامل، اللي فيه `pom.xml`، ماشي مجلد `src` وحده.
4. استناي حتى يكمل Maven تحميل المكتبات.
5. افتحي `src/main/java/com/mydailygrowth/Main.java`.
6. اضغطي على السهم الأخضر اللي بجانب `main` باش يخدم البرنامج.

### في Eclipse
1. اختاري **File → Import → Maven → Existing Maven Projects**.
2. حددي مجلد `MyDailyGrowth` ثم **Finish**.
3. افتحي `Main.java`.
4. كليك يمين ثم **Run As → Java Application**.

## التشغيل من Terminal
لازم يكون عندك JDK 17 أو أحدث وMaven 3.8 أو أحدث. افتحي Terminal داخل مجلد `MyDailyGrowth` ونفذي:

```bash
mvn clean compile
mvn exec:java
```

أول مرة، Maven يحتاج الإنترنت باش يحمّل SQLite JDBC. تقدري كذلك في Windows تضغطي مرتين على `run-windows.bat`، وفي macOS/Linux تشغلي `./run-macos-linux.sh`.

## كيفاش المشروع منظم؟

- `Main.java`: نقطة تشغيل البرنامج.
- `data/Database.java`: حفظ واسترجاع البيانات من SQLite.
- `model/`: الكلاسات اللي تمثل العادات والمزاج والتعلم والصلاة.
- `service/`: حساب الالتزام والفترات اليومية والأسبوعية والشهرية.
- `ui/`: الواجهات والألوان والرسوم البيانية.
- `export/`: تصدير التقارير إلى CSV.

## وين تتحفظ بياناتك؟

البرنامج ينشئ `habit_tracker.db` داخل مجلد التشغيل. العادة الجديدة يبدأ حساب الالتزام تاعها من تاريخ إضافتها؛ العادات القديمة اللي جاية من النسخ السابقة نحافظو على بياناتها ونعتبرو تاريخ بدايتها قديماً لأن النسخ القديمة ما كانتش تخزن تاريخ الإنشاء. ما تمسحيهش إذا حبيتي تحتفظي بالعادات والسجلات. ديري نسخة احتياطية منه والبرنامج مغلق.

## ملاحظة
العادات العادية محسوبة كعادات يومية. الصلاة عندها صفحة مستقلة بخمس خانات: الفجر والظهر والعصر والمغرب والعشاء. الإحصائيات تعتمد على المعلومات اللي تدخليها بنفسك. النسخة الحالية ما فيهاش تنبيهات تلقائية ولا مزامنة سحابية.

## جداول تكرار العادات (V5)
يمكن ضبط كل عادة على أحد الأنواع التالية:
- يومياً (وهو الإعداد الافتراضي للعادات القديمة بعد التحديث).
- أيام محددة من الأسبوع، مع اختيار أي مجموعة من الاثنين إلى الأحد.
- هدف أسبوعي من 1 إلى 7 مرات، مثل 3 مرات في الأسبوع.

أصبحت نسبة الالتزام في صفحة العادات ولوحة الإحصائيات تعتمد على الفرص المطلوبة حسب الجدول، وليس على كل أيام التقويم. في الهدف الأسبوعي تُحتسب حتى قيمة الهدف فقط في كل أسبوع؛ وتبقى الإنجازات الإضافية محفوظة في السجل دون رفع النسبة فوق 100%. تظهر الأيام غير المطلوبة بشرطة ولا يمكن تحديدها. يضيف تحديث SQLite أعمدة جديدة بقيم افتراضية تجعل العادات القديمة يومية، ولا يحذف سجل الإنجازات السابق.
